# OH Finance Public Landing Page

## Scope

Implemented locally on 2026-10-03. No commit, push, deployment, database operation, or secret change was performed.

- Anonymous visitors at `/` see the new Arabic RTL public page.
- An authenticated owner still sees the existing dashboard at `/`.
- A platform administrator still follows the existing redirect to `/platform`.
- Login, logout, password-reset paths, permissions, and private routes retain their existing behavior.
- API code, DTOs, business logic, Prisma schema, migrations, Supabase, and Redis were not modified.
- No new dependencies were added. Existing React, Lucide, and Radix-based UI components are reused.

## SEO and Deployment

- Static HTML provides the public title, description, Open Graph title/description/type/site name, and existing favicon.
- Client route metadata marks private screens `noindex, nofollow` and builds public Open Graph image/URL from the current origin.
- Vercel web response headers also mark private URL paths unindexable. This is indexing control, not a replacement for server authorization.
- Social crawlers that do not execute JavaScript may not see the dynamically added Open Graph image/URL. Reliable image previews for those crawlers would require static production-origin tags or a separate prerendering step.
- No new environment variables, Vercel project changes, or DNS changes are required for the existing Services setup. Publish only through the normal approved commit/deployment workflow.
- Moving administration to `admin.oh-finance.org` was not performed.
